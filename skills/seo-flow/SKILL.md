# The FLOW Growth Loop

An original five-stage framework for continuous SEO improvement, inspired by the FLOW methodology (flowframework.co, CC BY 4.0). Run as a repeating cycle, one loop per quarter per revenue area.

## F — Find (discover demand)
- Mine `search_web` for emerging queries, PAA shifts, and competitor launches
- `drift compare` on competitor-turned-target URLs reveals their recent bets
- Output: ranked list of opportunities (volume × fit × effort)

## L — Leverage (build on existing strength)
- `sitemap` + `audit`: find pages with equity but weak content (position 8–20 quick wins)
- Strengthen before creating: update, expand, re-schema existing near-misses
- Output: quick-win list ordered by distance-to-page-one

## O — Optimize (close technical gaps)
- `seo-audit` site-wide; fix by template not by page
- CWV field data via `psi`/`crux` (when GOOGLE_API_KEY set)
- Output: template-level fix tickets

## W — Win (publish to beat the SERP)
- Use `seo-content-brief` for each target
- Ship with `drift baseline` so regressions are caught
- Output: published pages with verification JSON attached

## L — Local (feedback → next loop)
- Rankings/reactions reviewed; failed experiments retired
- Learnings feed the next Find stage
- Output: loop retro + next cycle's opportunity seed list

## Cadence artifact
Maintain a kanban-style artifact: columns Find/Leverage/Optimize/Win/Local, cards with owner, status, and engine-audit scores before/after.
