# SEO Strategy Plans

Pick the template matching the business, then tailor with live data (`search_web`, engine audits).

## SaaS
1. Category pages per use-case × industry (the real query surface, not feature pages)
2. Comparison/alternative pages ("X vs Y", "X alternatives") — high intent
3. Integration pages ("X + {{tool}}")
4. Docs/guides as trust + AI-citation surface; enable llms.txt (`seo-geo`)
5. Free tools as link magnets

## Local
1. One city×service page per profitable combo (mind the 30/50 doorway gates in `seo-programmatic`)
2. GBP as the primary ranking surface (`seo-maps`)
3. Reviews + NAP consistency (`seo-local`)
4. Local proof content: projects, cases, landmarks

## E-commerce
1. Category architecture following search demand (`seo-cluster`), not internal taxonomy
2. Product schema completeness (`seo-ecommerce`)
3. Faceted navigation crawl control
4. Content hubs answering pre-purchase questions feeding category links

## Publisher
1. Topic clusters with hub pages; news/evergreen split with appropriate schema (NewsArticle vs Article)
2. E-E-A-T: author entities, review policies, dates (`content` command verifies signals)
3. Archive crawl hygiene (old URLs: 301, keep, or prune via sitemap audits)

## Agency
1. Service × location pages (doorway-gated)
2. Case studies as both proof and long-tail capture
3. Original research/data studies for authority links

## Roadmap artifact
Output 90-day plan: Days 0–30 foundations (technical audit fixes via `seo-audit`), 31–60 content architecture (clusters), 61–90 authority + iteration (drift monitoring via `seo-drift`).
